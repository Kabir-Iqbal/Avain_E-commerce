# 🛍️ Avian — Modern E-Commerce Store

**Avian** is a fully functional, modern e-commerce web application built with **Next.js**, **Tailwind CSS**, and **Sanity** as a headless CMS. It offers a smooth shopping experience with features like dynamic product listings, filtering, cart management, and secure Stripe payments.

---

## 🚀 Features

- 🔐 User authentication with Clerk.js
- 🏠 Home, Products, About & Contact pages
- 🛒 Add-to-cart with quantity control
- 🔍 Search and sort (by date or price)
- 📄 Product detail page
- 💳 Stripe-powered checkout & payment
- 📥 Downloadable order receipt after purchase
- ✅ Order success page
- 🔄 Responsive and dynamic UI

---

## 🧰 Tech Stack

- **Frontend:** Next.js, Tailwind CSS
- **Backend:** Sanity (Headless CMS)
- **Payment:** Stripe
- **Deployment:** Vercel

---

## 📦 Pages

- `/` — Home  
- `/products` — Product listing  
- `/products/[slug]` — Product detail  
- `/cart` — Cart items  
- `/checkout` — Checkout with Stripe  
- `/success` — Post-payment receipt page  
- `/about` & `/contact` — Informational pages
